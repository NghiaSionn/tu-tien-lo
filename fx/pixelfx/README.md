# pixelfx

Sheet trong thư mục này xuất từ [pixelfx](https://github.com/patch-gg/pixelfx) commit `044e12a` (MIT, xem LICENSE và NOTICE.md).

- `portal`: arcane/portal, giữ nguyên.
- `xp-orb-green|blue|gold`: pickups/xp-orb (bảng màu mặc định, xanh lam, vàng), cắt lại 32×32 theo đầu viên bằng `tools/pixelfx_import.py --xp-orb`.
